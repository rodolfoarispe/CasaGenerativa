# Casa Generativa

## Objetivo

Casa Generativa es un laboratorio vivo para investigar y documentar
una vivienda sostenible, utilizando materiales locales, documentación
continua y herramientas de IA.

## Filosofía

- Todo se documenta.
- Toda decisión tiene una razón.
- Todo cambio queda registrado.
- El conocimiento debe ser reutilizable.

## Estado actual

- Terreno adquirido.
- Plano topográfico disponible.
- Se está construyendo un GIS.
- El límite del terreno se reconstruye a partir de rumbos y coordenadas.
